The Foundry Bench

Looks up one operator supplied JA3 or JA3S fingerprint hash and reports the application and description recorded for it. One bell is struck and matched against exactly three reference bells whose notes are known, or against a larger set the operator brings to the bench.

What it does

The lookup runs against a small built in example table with three entries, or against an operator supplied CSV database given with -d, whose columns are fingerprint, application, and description. Usage, as the README gives it: ./analyze-tls-fingerprint [params]. Its one requirement is pandas.

Parameters

ParameterWhat the README says
-hShow help message and exit
-dPath to a CSV database file with fingerprint, application, and description columns. If omitted, the built in three entry example (dummy) table is used
-vEnable verbose logging (DEBUG level)
-oOutput file to save the lookup result (CSV format)

Stated limits

The built in table is a small example (dummy) set, not a full fingerprint database. The tool takes a hash as its only input: it does not read network traffic, connect to a server, or capture TLS sessions. Licence: the README closes with a copyright line and names no licence.
