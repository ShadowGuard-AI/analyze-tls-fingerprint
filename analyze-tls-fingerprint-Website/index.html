1The single task

analyze-tls-fingerprint takes one operator supplied JA3 or JA3S fingerprint hash and looks it up, reporting the application and the description recorded for that hash. It is focused on data analysis and reporting.

2The honest limits

Entered in the same size of type as the task, because an examiner's sheet hides nothing: the tool takes a hash as its only input, and it does not read network traffic, does not connect to a server, and does not capture TLS sessions. Anyone arriving here expecting a live traffic tool is told so at the second row, not at the last.

Examiner's marginal note

This tool never touches live traffic. It takes one presented hash, checks it against a recorded standard, and writes down a name and a short account.

3The two sources the lookup can consult

The first is the built in example table, described exactly as the source describes it: a small set of three entries, an example or dummy set, not a full fingerprint database.

Examiner's marginal note

The built in table holds only three dummy entries. A match outside that small set needs the operator supplied CSV below.

The second is an operator supplied CSV database whose columns are fingerprint, application, and description. The form below shows the column names as a headed but empty form, since the source gives the column names and no sample rows of an operator database, and this page invents none. The source also shows no worked lookup anywhere, so no example hash, matched application, or output CSV row appears here.

fingerprintapplicationdescription
   

4Getting and running the tool

git clone https://github.com/ShadowGuardAI/analyze-tls-fingerprint
./analyze-tls-fingerprint [params]

The four controls, entered as a candidate's manoeuvres, each with its mark:

-hShows a help message and exits.
-dGives the path to a CSV database file with fingerprint, application, and description columns. If it is omitted, the built in three entry example table is used instead.
-vTurns on verbose logging at DEBUG level.
-oNames an output file to save the lookup result in CSV format.
